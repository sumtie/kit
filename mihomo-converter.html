Mihomo 转换

多协议分享链接转 Mihomo (Clash Meta) YAML · 纯前端本地运行

vmess:// … +ws +tls vless:// … +ws +tls ss:// … +ws +tls trojan:// … +ws +tls tuic:// hysteria2:// / hy2:// VLESS XHTTP X-Padding ECH / ech-opts

输入链接 转换

支持 VMess / VLESS（WS + XHTTP）/ Shadowsocks / Trojan（WS+TLS）、TUIC、Hysteria2 分享链接，一键转换为 Mihomo (Clash Meta) YAML 节点。VLESS XHTTP 支持 TLS、ALPN、path / host / mode、X-Padding 与 ECH。若链接含 ECH 参数，将自动写入 ech-opts。

Mihomo 输出 YAML

勾选「输出完整配置」时，会把节点写入内置 mihomoConfig.yaml 的 proxies: 段。关闭完整配置且勾选「精简配置」时，输出可直接使用的最小配置：端口 / 日志、直连节点、转换节点、全节点选择组与一条 MATCH 规则。两者都关闭时只输出节点块。VMess 支持标准 Base64 JSON；VLESS XHTTP 会保留 xhttp-opts 及 X-Padding；ECH 参数会写入 ech-opts；TUIC / Hysteria2 为 QUIC，无需 WS。

纯前端本地处理 · 链接内容不会发送到任何服务器 · 使用前请确认合法合规
