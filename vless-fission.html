VLESS / VMESS 裂变

保留 UUID 与加密参数，批量替换连接地址与端口 · 纯前端本地运行 · 支持 vless:// 与 vmess://

基础节点 01 · 输入

粘贴一条完整的 vless:// 或 vmess:// 链接。工具会保留其中的 UUID、加密参数（security / sni / type / path / host / tls 等），只替换连接地址与端口。
